### 2. 테마 크롤링 (수동 복사 방식) ⭐ 실제 사용
- 새 버전 페이지는 Next.js SSR이라 JavaScript 렌더링 필요
- Selenium 또는 Kapture 필요하지만 복잡함
- **해결책**: 사용자가 페이지에서 직접 복사 → 파싱

#### 수동 작업 순서
1. 브라우저에서 테마 페이지 접속
2. 종목 리스트 전체 선택 + 복사
3. Python으로 종목명 추출
4. FDR로 종목 코드 매칭

```python
import FinanceDataReader as fdr
import pandas as pd

# 종목명 리스트 (사용자가 복사한 데이터에서 추출)
stock_names = ['엔투텍', '그린리소스', ...]

# FDR 매칭
kospi = fdr.StockListing('KOSPI')
kosdaq = fdr.StockListing('KOSDAQ')
all_stocks = pd.concat([kospi, kosdaq])

matched = []
for name in stock_names:
    result = all_stocks[all_stocks['Name'] == name]
    if not result.empty:
        code = result.iloc[0]['Code']
        matched.append({'name': name, 'code': code})
```

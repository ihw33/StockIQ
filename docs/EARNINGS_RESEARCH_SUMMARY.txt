TECHNICAL DETAILS
=================

DART OpenAPI:
  - Endpoint: https://opendart.fss.or.kr/api/
  - Key: Free registration required
  - Rate: Generous (good for free tier)
  - Data: Company filings, financial statements
  - Limitation: No future earnings schedule

OpenDartReader Library (Python):
  pip install OpenDartReader
  Github: https://github.com/FinanceData/OpenDartReader

Finnhub Earnings API:
  - Endpoint: https://finnhub.io/api/v1/calendar/earnings
  - Key: Free tier available
  - Parameters: from, to, token
  - Currently used by StockIQ for S&P500
  - File: services/ai-engine/collectors/economic_calendar_collector.py

earnings.kr:
  - Website: https://earnings.kr/calendar
  - Content: AJAX/JavaScript rendered
  - Scraping tool: Playwright or Selenium
  - Parsing tool: BeautifulSoup
  - No rate limiting (check ToS)
